14/Structure

Claude Code의 기본 구조

두 레벨로 나뉜다 — 프로젝트 안에서도 유저 레벨의 Skill을 항상 쓸 수 있다.

User Level  ~/.claude/

모든 프로젝트에서 공통으로 쓰는 Skill

~/.claude/ ├── CLAUDE.md ├── skills/ └── settings.json

Project Level  ./.claude/

이 프로젝트에서만 쓰는 Skill

my-project/ ├── CLAUDE.md └── .claude/ ├── skills/ └── settings.json
공통 Skill(유저 레벨) + 프로젝트 전용 Skill → 합쳐서 사용.

Rule of thumb — 3번 이상 반복되면 Skill로 만들어라

22/Modes

Claude Code 모드

default

기본값. 파일 수정·명령 실행 전마다 사용자에게 권한을 묻는다.

plan

코드 변경 없이 계획만 세움. 읽기·탐색만 가능, 실제 수정은 차단.

accept edits on

파일 수정은 자동 승인. 중요한 명령은 여전히 확인. 반복 작업에 편함.

bypass permissionsRISK

모든 권한 묻기 생략. 빠르지만 위험 — 신뢰할 수 있는 작업에만.

권한을 자주 물어봐서 번거롭다면 accept edits on으로 — Shift + Tab 으로 모드 순환 변경.
아예 안 묻게 하려면 실행 시 claude --dangerously-skip-permissions (bypass) 옵션 추가.
