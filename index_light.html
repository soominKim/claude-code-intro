03/Difference

챗봇과의 차이

챗봇 (ChatGPT, Gemini)

접근 범위
브라우저 안의 대화창

질문 → 답변 (1턴)

Coding Agent (Claude Code, Codex)

접근 범위
파일 시스템 + 웹 + 도구
행동 방식
계획 → 도구 실행 → 반복

14/Structure

Claude Code의 기본 구조

두 레벨로 나뉜다 — 프로젝트 안에서도 유저 레벨의 Skill을 항상 쓸 수 있다.

User Level  ~/.claude/

모든 프로젝트에서 공통으로 쓰는 Skill

~/.claude/ ├── CLAUDE.md ├── skills/ └── settings.json

Project Level  ./.claude/

이 프로젝트에서만 쓰는 Skill

my-project/ ├── CLAUDE.md └── .claude/ ├── skills/ └── settings.json
공통 Skill(유저 레벨) + 프로젝트 전용 Skill → 합쳐서 사용.

실습 — Remotion + Skills로 영상 한 편 만들기

사전 — node -v 가 v20+ 나와야 함. 안 나오면 Claude Code에게 "Node.js 설치해줘".

$ npx create-video@latest # 템플릿: Hello World # 폴더: my-video # TailwindCSS: No # Add agent skills? → Yes # find-skills? → Yes
Step 02 · 터미널 1
$ cd my-video $ npm i $ npm run dev # → localhost:3000 # (이 창 끄지 말것)
Step 03 · 터미널 2
$ cd my-video $ claude # 새 창 열어서 # 영상 주문은 # 여기서
Step 04 · MP4 출력
$ npx remotion render # → out/ 폴더에 .mp4 생성 # 최종 결과물
Step 03에 입력 — Prompt

"제품 소개 영상을 만들어줘. · 길이 15초 · 첫 5초 제품명 "TaskFlow" 가운데 페이드인 · 중간 5초 기능 3개(빠른 작업 관리·팀 협업·자동 리포트) 순차 등장 · 마지막 5초 "지금 시작하세요" CTA · 배경 진한 남색·텍스트 흰색·모던 · 기존 Composition 건드리지 말고 새 Composition으로."

실습 — Agent Teams로 도시락 서비스 기획안

Prompt

"Agent Teams를 사용해서 직장인 점심 도시락 배달 서비스 런칭 기획안을 만들어줘. 팀원 4명을 생성:
· 팀원1 — 시장 조사 (시장 규모·타겟·트렌드)
· 팀원2 — 경쟁사 분석 (직·간접 경쟁·차별화)
· 팀원3 — 예산안 (초기 투자·운영비·BEP)
· 팀원4 — 일정표 (5단계 로드맵·마일스톤)
각 팀원이 작업을 마치면 결과를 하나의 기획안으로 종합해줘."

→ 팀원들이 서로 메시지를 주고받으며 공유 작업 목록을 본다. 메인은 조율만, 컨텍스트가 차지 않음.

활성화 — 기본은 OFF

환경 변수 CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1 로 활성화. settings.json에:

{ "env": { "CLAUDE_CODE_EXPERIMENTAL_ AGENT_TEAMS": "1" } }
잘 작동하는 조건
  • 역할이 서로 독립적이다
  • 서로 기다리지 않고 동시 탐색 가능
  • 발견을 교환·도전해야 결과가 나옴

Claude Code 모드

default

기본값. 파일 수정·명령 실행 전마다 사용자에게 권한을 묻는다.

plan

코드 변경 없이 계획만 세움. 읽기·탐색만 가능, 실제 수정은 차단.

bypass permissionsRISK

모든 권한 묻기 생략. 빠르지만 위험 — 신뢰할 수 있는 작업에만.

권한을 자주 물어봐서 번거롭다면 accept edits on으로 — Shift + Tab 으로 모드 순환 변경.
아예 안 묻게 하려면 실행 시 claude --dangerously-skip-permissions (bypass) 옵션 추가.

vercel-labs/skills 같은 저장소에서 Skill 한 개만 설치.

→ 마켓플레이스는 앱스토어, 플러그인은 앱 묶음, 스킬은 앱 안의 기능. 설치 후 /find-skills 같이 바로 호출.

A/Appendix · HTML Output

[부록 A] HTML의 비합리적 효과

Claude Code의 출력을 Markdown 대신 HTML로 받기 시작하면 결과물의 품질·가독성·공유성이 한 단계 올라간다.

🧱

정보 밀도

표·SVG·차트·코드·이미지를 한 화면에 — Markdown으론 표현 불가.

📖

가독성

100줄 넘는 .md는 안 읽힌다. HTML은 탭·링크·반응형으로 정리.

🔗

공유 쉬움

브라우저에서 바로 열림. 동료에게 링크 한 줄로 끝.

🎚️

양방향 인터랙션

슬라이더·노브로 디자인 조정, "copy as prompt" 버튼까지.

🧠

데이터 통합

파일·MCP·Git·웹 등 Claude Code의 풍부한 컨텍스트를 한 파일에.

Markdown 출력 — 기존 방식

ASCII 다이어그램, 유니코드로 색 추정, 100줄 넘으면 스크롤만 함. 동료한테 보내려면 첨부 파일.

HTML 출력 — 새 방식

탭·콜랩서블·인터랙티브 SVG·diff 렌더링. 링크 한 줄로 공유. 누가 봐도 끝까지 읽음.

시작 방법: 거창한 설정 없이 — 프롬프트 끝에 "HTML 파일로 만들어줘" 한 줄만 붙이면 끝.

B/Appendix · HTML Use Cases

[부록 B] HTML로 시키는 5가지 — 예시 프롬프트

01 · Spec & 탐색 Explore

여러 옵션을 한 화면에 펼쳐 비교 → 정한 방향으로 계획 문서.

"온보딩 화면에 대해 6가지 다른 접근(레이아웃·톤·밀도)을 만들어서 한 HTML 그리드에 나란히 비교해줘. 각 카드에 trade-off도 표시."
02 · 코드 리뷰 Review

diff·주석·심각도 색상으로 PR을 한 페이지에 정리.

"이 PR을 HTML 아티팩트로 리뷰해줘. 스트리밍·백프레셔 로직 중심으로, diff에 inline 주석 + 심각도 색상 코딩."
03 · 디자인·프로토타입 Prototype

슬라이더·노브로 직접 만져보고 좋은 값만 copy.

"체크아웃 버튼 클릭 애니메이션 프로토타입. 슬라이더 여러 개로 조정하고, 'copy params' 버튼으로 마음에 든 값 복사."
04 · 리포트·학습 Explain

다이어그램 + 코드 스니펫 + gotcha 섹션으로 한 번에 이해.

"rate limiter 코드를 읽고 한 장짜리 HTML explainer 만들어줘. 토큰버킷 다이어그램 + 핵심 코드 3-4개 주석 + 'gotchas' 섹션."
05 · 커스텀 에디터 ★ Throwaway Editor

텍스트로 표현하기 힘든 작업 — 일회용 GUI를 만들고, 끝에 "copy" 버튼으로 결과를 다시 프롬프트로.

"이 30개 Linear 티켓을 재우선순위. Now / Next / Later / Cut 컬럼으로 드래그하는 HTML, 너의 추천 순서로 미리 정렬. 마지막에 'copy as Markdown' 버튼."
